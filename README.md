# Music Playlist Management System

## 📌 About the Project
The Music Playlist Management System is a C++ project designed to manage a collection of songs and perform basic playlist operations. It demonstrates how data structures can be used to organize and navigate music playlists.

## ✨ Features
- Add songs to the playlist
- Display all songs
- Search for a song
- Remove songs from the playlist
- Play the next or previous song
- Manage playlist records

## 🛠️ Technologies Used
- C++
- Data Structures
- Object-Oriented
